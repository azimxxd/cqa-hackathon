# Общая версия CQA

7 ноября 2026: сервер, интерфейс, AI и eval объединены в ветке `azamat/unified`,
подготовленной для общей `main`.

## Что объединено

- Интерфейс `azamat/ui-workspace`: список диалогов, транскрипт и доказательства,
  оценки, апелляции, решения проверяющего и версии чек-листа.
- Сервер и интеграционные исправления из `azamat/integration-fixes`.
- Шесть исправлений AI из `azamat/ai-review-fixes` — подробности в
  [AI_REVIEW_FIXES.md](AI_REVIEW_FIXES.md).
- Вся история `origin/main` / `origin/aldiyar/ai-v1` до `ba53c04` включительно:
  merge `e5b4789` с родителями `e4fe638` и `ba53c04`. Последняя разметка тиммейта
  сохранена без изменений относительно его ветки.

Конфликты в AI и автономном запуске тестов разрешены в пользу проверенной версии
с исправлениями: строгая валидация, ошибка после одного повтора вместо выдуманных
оценок, отсутствие скрытой замены модели, защита цитат, корректные паузы.
Улучшения промпта и структурных фактов тиммейта уже были перенесены на этапе ревью.
Дополнительно сохранены его исправления пустых настроек цены, пустых/логических
значений балла и преобразования nullable-схем Ollama (`ed28577`).

В `ai/merge.test.js` сохранены дополнительные сценарии тиммейта, адаптированные
к общему контракту: разрешённый N/A при длинной реплике клиента, обратная связь
при несуществующем доказательстве и ошибка при устойчиво невалидном JSON.
Три дополнительных регрессии сначала падали, после исправлений проходят.
Временные метки чатов переводятся в секунды от первой реплики согласно контракту.

- `git diff --check` — без ошибок. Новые коммиты проверены на известные форматы

Реальные LLM и API организаторов не вызывались. Файлы `eval/reports/`, уже
опубликованные тиммейтом в `main`, сохранены как история его запусков; они не
подтверждают точность объединённой версии. Для неё отдельный замер не проводился.

## Работа команды

После публикации используйте общую `main` как базу следующих веток. Изменения
объединены обычным merge, история тиммейта сохранена; переписывание истории и
force-push не требуются. Ветка `azamat/ai-review-fixes` сохраняет отдельный набор
исправлений для просмотра, а `azamat/unified` — результат объединения.

Запуск приложения и настройки описаны в [README.md](README.md).
Локальные `.env` и `data/cqa.db` остаются у каждого участника своими.
