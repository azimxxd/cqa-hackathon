Главное расхождение — завершение диалога: согласие по c07 составляет 44,6%. Второй проход применял строгое сочетание итога/предложения помощи с прощанием; существующая разметка часто принимает одно прощание. Нужна ручная сверка трактовки с организаторами, а не подгонка ответов под разметку.

По c08 расходятся `p1-ru-009`, `p1-kz-015`, `p1-en-014` и `p4-ru-002`. В первых трёх модель отметила раскрытие индивидуального ограничения до идентификации. Последний звонок неоднозначен: это продолжение предыдущего контакта, а раннее подтверждение отказа по заявке может трактоваться по-разному. Список и объяснения сохранены в `results/dev/quality-summary.json`.

Звонки оценивались по транскриптам, без прослушивания аудио. Токены, задержки и стоимость API отдельных диалогов не измерялись. Проверка кода и корректный JSON не заменяют независимую оценку качества модели.
