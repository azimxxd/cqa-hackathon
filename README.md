# CQA — Conversation Quality Analytics

Прототип для хакатона Freedom Broker. Система оценивает работу оператора в чатах и звонках по настраиваемому чек-листу, показывает доказательства по каждому критерию и поддерживает цикл «апелляция → решение проверяющего → пересчёт итога».

План команды, роли и таймлайн — в [PLAN.md](PLAN.md). Форматы данных и API — в [shared/schemas.md](shared/schemas.md).

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env   # вписать ORG_API_URL и GEMINI_API_KEY
npm start              # http://localhost:3000
```

Пока реальные маршруты не готовы, сервер отдаёт моки из `shared/mocks/` по тем же путям API.

## Команда и зоны ответственности

| Кто | Зона | Папки |

| Азамат | Сервер, БД, расчёт итога, контракты | `server/`, `shared/` |
| Алдияр | Интерфейс | `web/` |
| Нурлат | Оценка моделью, проверка точности | `ai/`, `eval/` |

## Как работаем с git

```bash
git checkout main && git pull
git checkout -b aldiyar/transcript-view   # префикс — своё имя
# ...работа...
git add -A && git commit -m "web: transcript view"
git push -u origin aldiyar/transcript-view
gh pr create --fill && gh pr merge --squash --delete-branch
```

- Правим только свои папки. Изменения в `shared/` — через Азамата.
- Пушим минимум раз в час. Перед merge проверяем, что `npm start` поднимается.
- Общий синк на 4, 8, 12, 16 и 20 часах: все подтягивают `main` и вместе прогоняют полный сценарий.
- `.env` с ключами не коммитим.

## Модель и стоимость

Заполнить к 20-му часу: модель, средняя стоимость одной оценки с учётом всех вызовов, среднее время и точность на ручной разметке (`npm run eval`).
