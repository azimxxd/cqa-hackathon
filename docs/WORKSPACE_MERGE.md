# Объединённый интерфейс CQA

- `#dialogs` и `#dialog/<id>` открывают одно рабочее пространство. В нём есть лента с фильтрами, переписка с плеером и правая панель оценки. На узком экране панели идут друг за другом. В верхней панели доступны режимы оператора и проверяющего, выборка и редактор чек-листа. Существующие маршруты апелляций, версий, статистики и экспорта доступны из навигации.
- Выборка использует сохранённые `source_ids` из канонического предпросмотра экспорта. Пустой код показывает все диалоги. Импорт доступен отдельным действием. Пакетная оценка отправляет только ID открытой выборки.
- Статус моделей берётся из `GET /api/ai/status`. Кнопка расшифровки отправляет `POST /api/conversations/:id/transcription` с `{"force":false}`, затем опрашивает тот же маршрут методом GET. Плеер использует `GET /api/audio/:id`. Gemini заменяет только отображаемый текст реплик по ID. Служебные сообщения, исходные позиции и привязки доказательств берутся из оригинала. Ранее импортированные результаты Algos показывают, что стоимость API не измерялась.
- Изменены `api.js`, `app.js`, `styles.css`, `ui.js`, `ui.test.js`, `views.js`. Добавлены `workspace.js` и `workspace.test.js`.

## Переоценка по выбранному тексту

Одиночная переоценка отправляет `transcript_source: "gemini"` только для звонка с открытой завершённой расшифровкой. Исходный режим, чаты и пакетная оценка отправляют `"original"`. При `409` кнопка переоценки по Gemini блокируется и предлагает обновить диалог. Уже показанный результат сохраняется, а карточка берёт подпись об использованном тексте из `evaluation.transcript_source`. Для старых оценок без поля указан оригинал. Если отображается другой текст, карточка сообщает об этом рядом с результатом.
