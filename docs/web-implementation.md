# Интерфейс экспорта CQA и редактор чек-листа

Экран `#submission` проверяет набор Saw-cell через API. ID группы задаётся отдельно от DEV/PROD. Предпросмотр показывает полноту, состав, фактические модель и режим, ошибки по диалогам, критерии и номера реплик. Официальный JSON доступен в сворачиваемом блоке. Скачивание управляется полем `ready`, поэтому полный набор с допустимыми строками `status: error` можно скачать. При ответе 409 отображаются обновлённые причины блокировки.

Редактор создаёт новую версию чек-листа. Критерии можно добавлять и удалять, выбирать существующий раздел, менять описание, тип, вес, условия N/A, начисление баллов и признак грубой ошибки. Для шкал редактируются значения и подписи. При переключении типа значения шкалы остаются в форме до сохранения. Новые критерии получают постоянный UUID. В карточке оценки Algos отмечено, что токены и стоимость API не измерялись.

## Изменённые пути

- `web/api.js` — запросы предпросмотра и скачивания, детали HTTP-ошибок.
- `web/app.js` — маршрут, обработчики формы, скачивание и переход к реплике.
- `web/checklist-editor.js` — поля, редактирование и сериализация критериев.
- `web/styles.css` — стили форм, таблицы и раскрываемых подробностей.
- `web/submission.js` — представление экрана экспорта и предпросмотра.
- `web/views.js` — подключение редактора и отображение использования Algos.
- `web/checklist-editor.test.js` и `web/submission.test.js` — тесты редактора и экспорта.
- `web/WEB_IMPLEMENTATION_REPORT.md` и `web/REPORT.md` — отчёты.
