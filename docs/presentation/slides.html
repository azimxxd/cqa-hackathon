Азамат · Нурлат · Алдияр2026
Задача

Ручной контроль качества не масштабируется

Как сейчас

  • Проверяющий читает чат или слушает звонок целиком
  • Выборочная проверка — малая доля диалогов
  • Оценки разных людей расходятся, обоснования нет
  • Спорить с оценкой сложно — непонятно, на что ссылаться

Что делает CQA

  • Оценивает каждый диалог по 8 критериям официального чек-листа
  • Каждый ответ — с обоснованием и ссылкой на реплику / момент записи
  • Оператор подаёт апелляцию, проверяющий решает, итог пересчитывается
  • RU / KZ / EN, чаты и звонки, итог 0–100

Как это работает

Путь диалога от API до итоговой оценки

1. ИмпортДиалоги из API организаторов по group_id. Звонки расшифровываются (faster-whisper / Gemini).
→
2. ОчередьExpress + SQLite. Задания оцениваются параллельно, настройки модели фиксируются.
→
3. Факты кодомПаузы, первая реакция, ожидание, идентификация — считаются без модели.
→
4. МодельПромпт из активного чек-листа + факты. Qwen локально или Gemini.
→
5. ПроверкаОтвет валидируется кодом. Ошибка → 1 повтор с обратной связью.
→
6. ИтогБаллы по весам, N/A с перераспределением, флаг грубой ошибки.

Сервер

Express API, встроенный node:sqlite, очередь, расчёт, апелляции, экспорт.

AI-слой

Промпт, правила по критериям, провайдеры Ollama/Gemini, валидация, расшифровка.

Интерфейс

Чистый HTML/CSS/JS, готов к встраиванию в Dynamics 365.

CQA · Saw-cell03
Оценка одного диалога

Модель не выдумывает — каждое её слово проверяется

Строгая валидация

ID реплик существуют, значение из шкалы, N/A — только где разрешено, для «Нет» указан проверенный участок.

Повтор, не подмена

Невалидный ответ → одна попытка с обратной связью → явная ошибка. Выдуманных оценок нет.

Проверка цитат

Цитаты, которых нет в диалоге, получают бейдж Требует проверки

Защита от prompt injection

Текст диалога передаётся модели как недоверенные данные.

Самосогласованность

LLM_SAMPLES=3: несколько прогонов и голосование по да/нет/N/A, нижняя медиана по шкале.

c04 · Консультация · Нет · 0 / 20
«Оператор не ответил про комиссию, см. m010»
→ клик по m010 прокручивает чат к реплике

Промпт строится из чек-листа

Критерии нигде не захардкожены — промпт собирается из активной версии.

Редактор версий

Заменили критерий → новая версия → модель переоценивает только изменённые критерии.

Расчёт итога

Шкала → баллы по весу, N/A исключается с перераспределением, округление до 2 знаков.

Доказательства и апелляции

Каждую оценку можно проверить и оспорить

ОценкаОтвет, баллы, вес и обоснование по каждому критерию
→
ДоказательствоКлик по реплике → прокрутка чата или перемотка записи звонка
→
АпелляцияОператор оспаривает критерий и оставляет комментарий
→
РешениеПроверяющий видит фрагмент, подтверждает или меняет оценку
→

Прозрачность

Оператор видит, за что снят балл, а не только цифру.

История

Оценка модели и решение человека хранятся раздельно — можно мерить точность.

Звонки

Плеер с переходом к нужному фрагменту записи по метке времени.

CQA · Saw-cell06
Модели

Свой GPU или облако — одна переменная

LLM_PROVIDER=ollama

Qwen3.6-35B-A3B локально

NVIDIA L40S + Ollama. Данные не покидают контур, $0 за вызов — платится только аренда GPU.

LLM_PROVIDER=gemini

Gemini 3.1 Flash Lite

Облако без своего железа. Стоимость считается по токенам каждого вызова и видна в интерфейсе.

LLM_PROVIDER=auto

Автоматически

Qwen, пока GPU-сервер отвечает (проверка каждые 20 с), иначе Gemini. Модель записывается в каждую оценку.

Расшифровка звонков

faster-whisper на том же GPU или Gemini audio — звонок превращается в реплики с метками времени и оценивается так же, как чат.
