# Интерфейс CQA

Нативные ES-модули, HTML и CSS без сборки. Сервер раздаёт эту папку автоматически:
из корня проекта запустите `npm start` и откройте http://localhost:3000.
Все данные загружаются с существующего API. На пустой БД показывается предложение
импортировать диалоги; подстановка демонстрационных данных в приложении отсутствует.

## Рабочие экраны

- `#dialogs` и `#dialog/<id>`: единое рабочее пространство с лентой, поиском,
  фильтрами и прогрессом оценки слева, перепиской и аудио по центру, оценкой справа.
  В верхней панели находятся выборка, импорт, режим работы и редактор чек-листа.
  Доказательства подсвечивают исходные ID реплик и перематывают запись.
- Для звонка доступны асинхронная расшифровка Gemini, состояния ожидания и ошибок,
  переключение исходного текста и Gemini, переоценка по выбранному тексту.
  Карточка явно показывает, на каком тексте основана сохранённая оценка.
- `#appeals`: открытые/решённые апелляции, создание решения, изменение ответа,
  evidence и диапазона. Решённая апелляция открывает именно свою Evaluation,
  даже если позже созданы новые оценки.
- `#checklist`: добавление и удаление критериев, редактирование названия, описания,
  типа, веса, N/A, шкал, раздела и признака грубой ошибки. Сохранение создаёт новую
  версию. Запуск переоценки выполняется отдельно пользователем.
- `#submission`: проверка и скачивание официального JSON для Saw-cell. Набор DEV/PROD
  и фактический ID группы задаются отдельно; доступны версия и original/final,
  проверка полноты, модель, причины ошибок и доказательства.
- `#stats`: распределение последних оценок, токены, стоимость и время вызовов.

Параметры карточки: `?version=<id>` — выбранная версия чек-листа,
`?evaluation=<id>` — точная историческая оценка. Во время оценки ID job сохраняется
в sessionStorage, чтобы после обновления страницы продолжить показ прогресса.

## Оформление и доступность

Визуальные правила взяты из `elayadesign/ai-design-skills`, навык
`landing-page-design`: Manrope, ограниченная шкала отступов и размеров текста,
Phosphor, плоские поверхности, один зелёный акцент и полноценные состояния.
Шрифт и иконки лежат локально; запросов к CDN нет. Лицензии — в assets/.

Стили ограничены `.cqa`, основной контейнер один — `#cqa-root`.
Адаптер Dynamics 365 сохранён. Есть навигация клавиатурой, ссылка пропуска навигации,
видимый focus, нативные dialog/details/form, подписи полей, сообщения ошибок,
состояния загрузки и пустого списка. На ширине 390 px проверено отсутствие
горизонтального переполнения. Учитывается prefers-reduced-motion.

`api.js` — HTTP и ошибки; `ui.js` — безопасное отображение, форматирование и иконки;
`workspace.js` — три панели, аудио и расшифровка; `views.js` — остальные экраны; `app.js` — маршруты и действия.

## Проверки первого прохода

- `npm test`: серверные тесты плюс клиентские проверки экранирования, audio_url,
  ошибок API и кодирования ID.
- В браузере на отдельной временной БД: поиск/пустой результат/фильтры, доказательство
  с переходом и фокусом, импорт со стабом API, пакетная оценка в fake-режиме,
  создание апелляции, решение change (77.69 → 85.38; original 77.69), сохранение
  чек-листа v2, открытие исторической оценки после новых оценок, статистика,
  мобильная форма и компоновка.

Проверки первого прохода выше относятся к предыдущей версии интерфейса.
Текущее объединение и реальные вызовы Gemini описаны в
[TEAMMATE_MERGE.md](../docs/TEAMMATE_MERGE.md).
